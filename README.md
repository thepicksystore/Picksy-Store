# Picksy Store

Picksy is a product-discovery affiliate website concept: trending, affordable and useful finds, curated for you.

## Current milestone: Home Page v1

This first build contains:
- Responsive Picksy homepage
- Hero/search UI
- Categories
- Trending / New Finds / Picksy Picks
- Under ₹299 banner
- Festival banner
- Product cards
- Product detail route
- Mobile navigation
- GitHub Pages-compatible Vite base path

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Next milestone
